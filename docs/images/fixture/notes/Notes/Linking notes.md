# Linking notes

Links are the actual content of a note system. Folders express one hierarchy; links express as many relationships as you care to write down.

Write the link when you write the note. Retroactive linking sessions sound diligent and almost never happen — and when they do, you link what you can still remember, which is exactly the set of notes that did not need help.

Give links a reason. "See [[Atomic notes]]" is weaker than "this only works if each note holds one idea — see [[Atomic notes]]". The sentence around the link is what makes it findable later.

Backlinks are not a substitute. A backlink tells you *that* something pointed here; it does not tell you why.
