# Zettelkasten method

A Zettelkasten is a network of short, self-contained notes that link to each other. The value is not in any single note — it is in the density of the connections between them.

Three rules keep it working:

1. **One idea per note.** If a note needs the word "and" in its title, it is two notes.
2. **Write in your own words.** A quote you did not rephrase is a quote you did not understand. See [[Literature notes]].
3. **Link on the way in, not later.** A note filed without links is a note you will never find again. See [[Linking notes]].

The method is slow at the start and compounds later. The first hundred notes feel like busywork; somewhere past that, the box starts answering questions you did not ask it.

## Why it resists search

Keyword search finds the notes you remember writing. The point of a Zettelkasten is the note you *forgot* you wrote — which is why link density matters more than any folder structure, and why [[Semantic search]] is a natural complement rather than a replacement.
