# Atomic notes

An atomic note holds exactly one idea, stated in full, in your own words. It should make sense to a reader who has never seen the note it came from.

The test: can you link to it from three different contexts without the link feeling strained? If not, the note is either too broad (split it) or too narrow (it is a fragment, not an idea).

Atomicity is what makes [[Zettelkasten method]] work at scale. A note about six things can only ever be linked as "that note about six things"; six notes about one thing each can be recombined endlessly.

Common failure: the *summary note*. It feels productive, links to nothing specific, and is never read again. Prefer [[Progressive summarization]] on the source, plus atomic notes for the ideas worth keeping.
