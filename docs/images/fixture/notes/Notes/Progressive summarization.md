# Progressive summarization

Summarize in passes, not in one sitting. First pass: keep the source intact, bold the sentences that carried weight. Second pass: highlight within the bold. Third pass: write a few lines at the top in your own words.

Each pass happens only when you come back to the note for a real reason. A note you never revisit never gets summarized — which is correct, because it was never worth the effort.

The output of the last pass is usually the seed for one or two [[Atomic notes]].

Failure mode: summarizing everything immediately. That is just re-typing, and it front-loads work onto material you have not yet found a use for.
